# Platformer Adventure
**Context:** University Assignment • May 2, 2025

**Description:**
I took extra time on this project (and the previous one) to more deeply polish gameplay and environment — refining level design, adding custom art, and improving the overall player experience.

## Implementation
- Used free Unity asset **"Simple 2D Platformer"** solely for graphical sprites for the player and enemies.  
- Multiple levels  
  - Three distinct levels, each with unique layouts and challenges.  
- Custom sprites  
  - All additional environment art are student-created.  
- User-controlled player  
  - Movement left/right, jump, and smooth sprite flipping.  
- Jump mechanic  
  - Responsive jumping with ground-check logic.  
- Enemies  
  - At least two enemy types across levels (Level 3 features two enemies).  
- Score reporting  
  - Real-time score display via TextMeshPro UI.  
- Camera follow  
  - Smooth, clamped camera that tracks the player without leaving the background bounds.  
- Terrain & platforms  
  - Interactive platforms and hazards for player traversal.  
- Parallax backgrounds  
  - Two-layer parallax effect (background moves slower than foreground).  
- Start and end-game experience  
  - Finish-line trigger loads Level 2; UI button to restart Level 1.  
- Game-over handling  
  - Collision with any enemy immediately loads a Game Over scene.
